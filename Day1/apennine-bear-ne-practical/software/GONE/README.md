# GONE software directory

This directory contains the Apennine brown bear driver and its original parameter values.

Before class, copy the tested compiled programs from the appropriate official GONE Linux or macOS distribution into:

```text
software/GONE/PROGRAMMES/
```

Required files include:

```text
MANAGE_CHROMOSOMES2
LD_SNP_REAL3
SUMM_REP_CHROM3
GONE
GONEaverages
GONEparallel.sh
```

The repository does not currently bundle those platform-specific binaries. Test the complete directory on the same operating system students will use.

The driver deletes generic temporary files in its current directory. The lesson therefore creates a private copy for each student group before running it.
